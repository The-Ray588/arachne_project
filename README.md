# 🕷️ ARACHNE — Calibre 12 Suspension Automatique

**ARACHNE** — это концептуальные механические часы с живым золотым пауком вместо стрелок. Проект выполнен в эстетике люксовых швейцарских механизмов (Skeleton Dial) с глубоким чернильным фоном, сложной геометрией лапок и **модульной архитектурой**. Система поддерживает добавление новых функций без изменения основного кода (плагинная архитектура).

---

## ✨ Особенности

- **Живой паук-механизм:** Лапки паука выполняют роль стрелок (секундная, минутная, часовая) и вращаются вокруг светящегося тела.
- **Сложная геометрия:** Каждая лапка имеет суставы (изгибы), а тело состоит из нескольких бликов и теней для создания объёма.
- **Реалистичное движение:** Анимация с эффектом «пружины» (`cubic-bezier`), которая имитирует инерцию механических деталей.
- **Синхронизированный звук:** Громкий механический щелчок («тик») каждую секунду, генерируемый через **Web Audio API** без использования внешних аудиофайлов.
- **Визуальная обратная связь:** При каждом тике в центре паука вспыхивает золотое свечение.
- **Точное время:** Используется алгоритм самокоррекции (`setTimeout` с расчётом задержки до ближайшей миллисекунды), поэтому часы никогда не «уплывают».
- **Модульная архитектура:** Основной код (`app.js`) не меняется при добавлении новых функций. Все дополнительные модули подключаются отдельно.
- **Никаких библиотек:** Проект написан на чистом HTML, CSS и ванильном JavaScript.

🚀 Установка и запуск

Без сервера

1. Скачайте или скопируйте все файлы из структуры проекта в одну папку.
2. Откройте файл index.html в любом современном браузере (Chrome, Firefox, Safari, Edge).
3. Важно: Нажмите в любом месте страницы, чтобы активировать звук (политика браузеров требует взаимодействия для запуска Web Audio API).

С локальным сервером (рекомендуется)

Чтобы избежать проблем с CORS и получить доступ к API погоды, запустите локальный сервер:

· Вариант 1 (VS Code): Установите расширение Live Server и нажмите «Go Live».
· Вариант 2 (Python): В терминале введите python -m http.server 3000, затем откройте http://localhost:3000.
· Вариант 3 (Node.js): Введите npm install -g serve, затем serve.

🎛️ Настройка

Изменение громкости звука

В файле app.js найдите строку внутри функции playTick():

```javascript
gainNode.gain.setValueAtTime(0.25, audioCtx.currentTime);
```

Измените значение 0.25 на нужное.

Изменение скорости/плавности анимации

В файле app.js в функции tick() найдите:

```javascript
secEl.style.transition = 'transform 0.15s cubic-bezier(0.4, 2.08, 0.55, 0.44)';
```

Измените 0.15s на другое значение.

Изменение цветов

В файле app.css в блоке :root измените значения переменных:

```css
:root {
    --ink-500: #171826;  /* Цвет фона */
    --brass-100: #f6e6c1; /* Светлое золото */
    --brass-500: #a8873f; /* Темное золото */
}
```

📝 Подробная механика работы

Как работает точное время?

Функция scheduleTick() рассчитывает задержку до начала следующей секунды по формуле:

```javascript
const delay = 1000 - (Date.now() % 1000);
```

Это позволяет избежать «дрейфа» времени.

Почему стрелки не вращаются назад?

Функция forwardOf() всегда добавляет 360°, если целевой угол меньше текущего, чтобы лапки паука никогда не отматывались назад.

Как генерируется звук «тик»?

Звук создаётся через Web Audio API без внешних файлов. Осциллятор с частотой 2000 Гц затухает до 800 Гц за 0.03 секунды.

Как работает модульная архитектура?

Все плагины подключены через обычные теги <script src="..."> в index.html. Основной код часов (app.js) не изменяется при добавлении новых функций. Плагины используют глобальный объект window.Clock для обмена данными и синхронизации с часами.

❓ Часто задаваемые вопросы (FAQ)

Почему нет звука при открытии страницы?
Браузеры блокируют автоматическое воспроизведение звука. Просто кликните в любом месте страницы.

Можно ли использовать этот код в коммерческих целях?
Да, код создан в образовательных целях и свободен для использования, изменения и распространения.

Как изменить форму паука?
В файле index.html в блоке <g id="spider"> замените координаты в тегах <path class="leg"> или <path class="spider-body">. Вы можете нарисовать собственный SVG-путь.

Как добавить новый плагин?
Создайте новый файл .js и подключите его в index.html строкой <script src="имя_файла.js"></script>. Основной код часов при этом останется неизменным.
