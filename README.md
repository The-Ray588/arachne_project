# 🕷️ ARACHNE — Calibre 12 Suspension Automatique

**ARACHNE** — это атмосферные механические часы, выполненные в эстетике люксовых швейцарских механизмов (skeleton dial). Вместо привычных стрелок здесь используются **лапки паука**, которые вращаются вокруг светящегося золотого тела. Проект написан на чистом HTML, CSS и JavaScript без использования внешних библиотек и фреймворков.

## ✨ Особенности

- **Живой механизм:** Секундная, минутная и часовая "лапки" вращаются с реалистичным механическим затуханием (эффект пружины).
- **Сложная геометрия паука:** Лапки имеют суставы (изгибы), тело состоит из нескольких бликов и теней для создания объема.
- **Атмосферный дизайн:** Фоновое "дыхание" света (ambient pulse), глубокие чернильные градиенты и золотое свечение (brass) в стиле стимпанк.
- **Синхронизированный звук:** Реализован механик-щелчок (тик) каждую секунду через **Web Audio API** (без использования аудиофайлов).
- **Визуальная обратная связь:** При каждом тике в центре паука вспыхивает светящееся кольцо.
- **Точное время:** Код синхронизирован с системными часами с точностью до миллисекунды (механизм `setTimeout` с компенсацией дрейфа).
- **Отсутствие отката:** Стрелки никогда не вращаются назад при пересечении отметки "12" (реализована функция `forwardOf`).

## 🛠️ Технологии

- **HTML5** — семантическая разметка и инлайн SVG (векторная графика).
- **CSS3** — кастомные свойства (переменные), градиенты, сложные анимации (`cubic-bezier`), эффекты свечения и размытия.
- **Vanilla JavaScript (ES6+)** — логика времени, работа с DOM и генерация звука через Web Audio API.
